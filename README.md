# To Do List – Étape 3A

## Présentation du projet

Ce projet consiste à développer une application To Do List dans le cadre du parcours SYNVA. L’application permet de préparer la gestion de tâches universitaires et de projets en organisant les informations nécessaires à leur suivi.

## Objectif de l’étape 3A

L’objectif de cette étape est de rendre le formulaire de saisie des tâches dynamique à l’aide de JavaScript, à partir du formulaire HTML et CSS réalisé lors de l’étape 2A.

## Fonctionnalités réalisées

- Affichage d’un formulaire de saisie de tâche.
- Génération dynamique des listes déroulantes à partir des données définies en JavaScript.
- Sélection d’une catégorie, d’une priorité et d’un statut.
- Affichage des phases de réalisation correspondant à la catégorie sélectionnée.
- Utilisation de JavaScript pour gérer les listes de sélection.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
