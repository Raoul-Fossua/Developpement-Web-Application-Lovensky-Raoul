# Étape 2A — Formulaire de saisie d'une tâche

## Description

Réalisation d'un formulaire de saisie d'une tâche dans le cadre du projet de développement d'une application de gestion de tâches (To-Do List).

## Technologies

- HTML5
- CSS3

Le formulaire est réalisé sans JavaScript, conformément aux consignes de l'étape 2A.

## Accès au formulaire

🔗 https://lovensky.alwaysdata.net/step2A.html


## Objectif

Préparer l'interface de saisie des tâches avant l'intégration des fonctionnalités dynamiques dans les étapes suivantes.
