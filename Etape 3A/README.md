# To Do List – Étape 3A

## Présentation du projet

Ce projet s’inscrit dans le cadre du développement d’une application To Do List réalisée en HTML, CSS et JavaScript dans le cadre du parcours SYNVA.

L’objectif de l’étape 3A est de rendre le formulaire de saisie des tâches dynamique à partir des données définies en JavaScript.

## Objectifs de l’étape 3A

Cette étape consiste à :
- reprendre le formulaire de saisie réalisé à l’étape 2A ;
- utiliser JavaScript pour générer dynamiquement les options des listes déroulantes ;
- afficher les catégories, les priorités et les statuts à partir des listes de données ;
- adapter les phases de réalisation en fonction de la catégorie sélectionnée.

## Technologies utilisées

- **HTML5** : structure du formulaire ;
- **CSS3** : mise en forme du formulaire ;
- **JavaScript** : gestion des données et génération dynamique des listes déroulantes.

## Fonctionnement

Les listes de paramètres sont définies en JavaScript. Les options sont ensuite ajoutées aux listes déroulantes du formulaire.

Lorsqu’une catégorie est sélectionnée, les phases de réalisation correspondantes sont proposées.

## Suite du projet

Les prochaines étapes prévoient l’enregistrement des tâches dans le stockage local du navigateur (`localStorage`), puis l’affichage des tâches enregistrées dans un tableau récapitulatif.
