# Étape 2A – Formulaire de saisie d’une tâche

## Présentation

Cette étape consiste à créer un formulaire HTML permettant de saisir les informations d’une tâche dans l’application To Do List.

## Travail réalisé

- Création de la structure du formulaire en HTML ;
- Mise en forme des champs avec CSS ;
- Organisation des informations nécessaires à la saisie d’une tâche ;
- Adaptation de la présentation pour faciliter l’utilisation du formulaire.

## Technologies utilisées

- HTML5 pour la structure du formulaire ;
- CSS3 pour la mise en forme.

## Contraintes

Le formulaire est réalisé uniquement en HTML et CSS, sans JavaScript, conformément aux consignes de l’étape 2A.

## Objectif

Cette étape permet de disposer d’un formulaire statique qui servira de base à la dynamisation réalisée lors de l’étape 3A.
